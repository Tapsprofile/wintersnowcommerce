🚀 Quick Start Guide

  1. Upload Theme: Copy all files to wp-content/themes/wintersnow-commerce/
  2. Activate: Go to Appearance > Themes and activate WinterSnow Commerce
  3. Install Plugins: WooCommerce, Elementor, Unlimited Elements
  4. Configure: Use Theme Builder in Elementor to customize templates
  5. Tag Products: Add "Festive" tag to seasonal products
  6. Test: Verify all features using the QA checklist in README.md
